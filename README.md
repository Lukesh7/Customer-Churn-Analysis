# 📞 Telco Customer Churn Analysis & Prediction

A data analytics and machine learning project focused on understanding customer retention, identifying churn drivers, and building predictive models to forecast customer churn for a telecommunications provider.

---

## 📊 Overview

Customer churn is a critical metric for telecommunication companies. Retaining existing customers is significantly more cost-effective than acquiring new ones. This project analyzes demographic, account, and service usage data to pinpoint why customers leave and builds predictive models to identify at-risk customers proactively.

---

## 🎯 Objectives

- **Exploratory Data Analysis (EDA):** Identify key demographic and contractual patterns associated with customer churn.
- **Data Preprocessing:** Clean dirty/missing data, encode categorical features, and scale numerical distributions.
- **Machine Learning:** Train, evaluate, and compare baseline classification models (e.g., Logistic Regression, Random Forest, XGBoost).
- **Insights & Recommendations:** Translate data patterns into actionable business strategies for retention.
